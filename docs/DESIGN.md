# 设计说明

## 1. 目标

把一段带人声的音视频（含 BGM、纯人声、访谈、课程、播客），转成三种可直接使用的文字产品，并在生成前提供双语文本供人工核对。

核心不是"把声音转成字"，而是**在保真的前提下把口语整理成书面资产**。

## 2. 输入

| 类型 | 说明 |
|---|---|
| 本地文件 | mp4 / mkv / mov / mp3 / wav / m4a / flac |
| 网络链接 | 仅公开可下载内容；不做 DRM 绕过，产出物注明来源 |

## 3. 流水线

```
① 接入     文件或链接 → 抽音轨 → 16 kHz 单声道 + 原始音轨备份
② 预处理   VAD 切分（30–60 s，带重叠）→ 可选人声分离（重 BGM 时）
③ 识别     语种识别 → 路由到主/备 ASR → 文本 + 内部时间戳
④ 校准     术语表注入 → 逐段纠错（只改错，不改写）→ 数字/单位规范化
⑤ 结构化   信息单元抽取（带原文锚点）→ 归并去重 → 提纲
⑥ 生成     a 口播稿 / b 知识点报告 / c 快报 / 双语 txt
```

### 3.1 语种分层

| 梯队 | 语种 | 处理策略 |
|---|---|---|
| 第一 | 中文、英文 | 主力模型，逐段纠错 |
| 第二 | 日语、韩语、意大利语、德语、印地语等 | 同一流水线，纠错提示词切换语种 |
| 不覆盖 | 乌尔都语等长尾 | 明确报错，不做降级猜测 |

语种识别优先由 ASR 自带，识别置信度低时回退到独立 LID。

### 3.2 关键约束

- **两阶段处理**：S1 只纠错，S2 才改写/生成。一步到位会让模型边改边总结，信息被悄悄丢掉。
- **全链路锚点**：每个输出句子都能指回某个 segment id。时间戳内部保留，不进入交付物。
- **静音门控**：无语音段直接标记，不允许模型自由发挥。
- **内容哈希缓存**：同一素材不重复识别，长音频可断点续跑。

## 4. 输出规格

### a. 干净口播稿

- 第一人称、可朗读、段落化
- 保留：事实、数据、结论、因果、案例、限定条件、立场
- 删除：口癖、重复、寒暄、跑题、无信息量的过渡
- 长度约为原语音的 60–75%

### b. 知识点报告

每个知识点固定五段：是什么 / 为什么 / 怎么做 / 边界 / 关联。前置知识点地图，后附存疑清单。

### c. 简要快报

300–600 字 + 5–8 条要点 + 一句话结论。

### 双语 txt

三份：原文（纠错后）、译文、段段对照。中英混说按段标注，不强行统一。
